# 实验完整代码说明

## 一、项目概述

本项目实现了一款 **5级流水线 RISC-V 处理器内核**，支持 **RV32IM** 指令集（整数指令 + 乘除扩展），包含以下核心特性：

- **5级流水线**：取指（IF）、译码（ID）、执行（EX）、访存（MEM）、写回（WB）
- **数据前递（Forwarding）**：消除数据冒险
- **分支预测**：gshare 预测器 + 2路组相联 BTB（Branch Target Buffer）
- **乘除单元**：3周期 Booth 编码乘法器 + 迭代除法器
- **CSR 模块**：支持 trap/mret 异常处理机制
- **UART 外设**：AXI-Lite 接口的 UART IP
- **总线桥接**：内存接口到 AXI-Lite 协议桥

仿真环境使用 **Synopsys VCS**，测试基于 **RISC-V 官方 ISA 测试集** 和 **CoreMark 基准测试**。

## 三、处理器核心微架构

### 3.1 整体流水线结构

```
  ┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐
  │  IF  │ →  │  ID  │ →  │  EX  │ →  │ MEM  │ →  │  WB  │
  └──┬───┘    └──┬───┘    └──┬───┘    └──┬───┘    └──┬───┘
     │           │           │           │           │
  ┌──▼───┐  ┌───▼────┐  ┌───▼────┐  ┌───▼────┐  ┌───▼────┐
  │pc.v  │  │id.v    │  │ex.v    │  │dataram │  │wb.v    │
  │if.v  │  │regfile │  │mul.v   │  │banked  │  │        │
  │bp.v  │  │        │  │div.v   │  │        │  │        │
  └──────┘  └────────┘  └────────┘  └────────┘  └────────┘
```

### 3.2 各阶段核心模块

#### IF 阶段（取指）
| 模块文件 | 功能 |
|---------|------|
| `pc.v` | 程序计数器，支持 stall、分支重定向、预测跳转 |
| `riscv_core.v` (IF1/IF2逻辑) | 两级取指前端，适配同步 BRAM 时序 |
| `branch_predictor.v` | gshare + 2路BTB 分支预测器 |

#### ID 阶段（译码）
| 模块文件 | 功能 |
|---------|------|
| `id.v` | 指令译码，类型识别（R/I/S/B/L/U/J/CSR），立即数扩展 |
| `registerfile.v` | 32×32 通用寄存器堆，x0 硬连线为 0 |
| `if_id_reg.v` | IF/ID 流水线寄存器 |

#### EX 阶段（执行）
| 模块文件 | 功能 |
|---------|------|
| `ex.v` | ALU 运算（ADD/SUB/SLT/SLL/SRL/SRA/XOR/OR/AND），分支条件判断（BEQ/BNE/BLT/BGE/BLTU/BGEU），CSR 访问，预测验证 |
| `mul_3cycle.v` | 3周期 Booth Radix-4 流水线乘法器 |
| `div.v` | 迭代除法器（32周期，支持有符号/无符号 DIV/REM）|
| `id_ex_reg.v` | ID/EX 流水线寄存器 |

#### MEM 阶段（访存）
| 模块文件 | 功能 |
|---------|------|
| `dataram_banked.v` | Bank 交织数据存储器（Bank0: 偶地址, Bank1: 奇地址），支持非对齐访问 |
| `ex_dataram_reg.v` | EX/MEM 流水线寄存器 |

#### WB 阶段（写回）
| 模块文件 | 功能 |
|---------|------|
| `wb.v` | 写回数据选择（ALU 结果 / 存储器加载数据）|
| `dataram_wb_reg.v` | MEM/WB 流水线寄存器 |

### 3.3 辅助模块

| 模块文件 | 功能 |
|---------|------|
| `csr.v` | CSR 寄存器（mstatus/mie/mtvec/mepc/mcause/mcycle/minstret），异常处理 |
| `define.v` | 全局宏定义（指令编码、ALU 控制码、RISC-V 类型码）|

### 3.4 数据前递（Forwarding）

在 `riscv_core.v` 中实现，支持以下转发路径：

```
EX 阶段结果 → EX 阶段输入（向前递送 MEM 和 WB 阶段的结果）
  - dataram → ex_forwarded_rs1_data（MEM阶段结果转发）
  - wb → ex_forwarded_rs1_data（WB阶段结果转发）
  - dataram → ex_forwarded_rs2_data
  - wb → ex_forwarded_rs2_data
```

Load-Use 冒险检测：当 EX 阶段是加载指令且 ID 阶段需要相同寄存器时，插入 stall。

### 3.5 分支预测

采用 **gshare 预测器 + 2路组相联 BTB**：

- **gshare 方向预测器**：PC 与全局历史寄存器 GHR 异或后索引 PHT（2-bit 饱和计数器表）
- **BTB（分支目标缓冲区）**：256 项，2路组相联，LRU 替换策略
- **预测验证**：EX 阶段比较实际分支方向与预测，预测错误时冲刷流水线并重定向 PC

|------|------|

- `0x1000_0000`: TX Data（写）/ RX Data（读）

- `0x1000_0008`: RX Data（读取已接收数据）

## 五、测试框架

### 5.1 测试类型

| 测试类型 | 脚本 | 说明 |
|---------|------|------|
| ISA 单测试 | `run.sh single <test_name>` | 运行单个 RISC-V ISA 测试 |
| ISA 批量测试 | `run.sh isa 'rv32u[im]-p-*'` | 批量运行 ISA 测试并汇总结果 |
| 统一回归 | `run.sh all` | UART 烟雾测试 + ISA 回归 |
| 分支预测测试 | `run.sh bp` | 分支预测模式测试 + 统计 |
| CoreMark 基准 | `run.sh coremark [iterations]` | CoreMark 性能基准 |
| UART 测试 | `run.sh uart` | UART 功能测试 |
| CSR 计数器测试 | `run.sh minstret` | minstret 性能计数器 |

调试单个 ISA 用例可使用 `./run.sh isa rv32ui-p-add`，详细仿真输出保存在
`rtl/test_results/<时间戳>_isa_rv32ui-p-add.sim.log`，无需单独的调试运行脚本。

### 5.2 测试通过标准

- **通过**：`tohost` 寄存器值 = `1`
- **失败**：`tohost` 寄存器值 ≠ `1`（非零值）
- **超时**：在指定时间内未写入 tohost

### 5.3 仿真输出

测试平台在检测到 tohost 写入时自动输出：
- `[BP]` 行：分支预测统计（分支总数、误预测数、目标缺失数、准确率）
- `[PERF]` 行：性能统计（mcycle 周期数、minstret 指令数、CPI）
- `*** TEST PASSED ***` / `*** TEST FAILED ***`：最终测试结果

## 七、关键设计决策

1. **分支判断在 EX 阶段**：分支条件比较移至 EX 阶段，复用 ALU 操作数，减少 ID 阶段关键路径延迟
2. **IF1/IF2 前端**：双级取指前端适配同步 BRAM 单周期回读延迟，支持 stall 暂停时保留返回数据
3. **Bank 交织存储器**：数据存储器采用 Bank0/Bank1 偶奇交织，支持单周期非对齐访问
4. **MUL/DIV 流水线 stalling**：乘法/除法指令在 EX 阶段 stall 流水线直到运算完成，保证写回顺序正确性
5. **gshare 预测器**：全局历史与 PC 异或索引，256 项 PHT（2-bit 饱和计数器），2路 BTB 缓存目标地址
